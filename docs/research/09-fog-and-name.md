<a id="约定"></a>
## 约定

- **查询日期**：所有查询都在 2026-11-02 做。本篇汇总的是流程里各 Agent 当天的查询记录；审稿时（同日）只重跑了 [§0](#0-推荐) 四个名字的 GitHub 和 npm，以及推荐名和备选的 Wiktionary、Jisho 释义，其余没有重跑。
- **怎么查的**：
  - GitHub：`gh api users/<名>`（用户和组织共用一套命名空间），404 记为空着；同名仓库用 `gh api search/repositories` 按仓库名搜，表里的「仓库名搜索数」是返回的 total。每个名字查裸名、`<名>-app`、`<名>hq`，外语词再查常见转写变体。
  - 包管理器：查注册表接口。npm 用 `registry.npmjs.org/<名>`，PyPI 用 `pypi.org/pypi/<名>/json`，crates 用 `crates.io/api/v1/crates/<名>`，Homebrew 查 `formulae.brew.sh` 的 formula 和 cask。
  - 发行版同名包：Repology。
  - App Store：iTunes Search API（`itunes.apple.com/search`，`country` 取 `cn`、`us`，日语词加 `jp`），看应用名里有没有这个名字。
  - 外语词：Wiktionary（定义接口和 wikitext）、Jisho API、Logeion（LSJ、Middle Liddell、荷马词典）、PerseusDL 的希腊文和拉丁文原文、冰岛语 BÍN 词形库、巴斯克语 Elhuyar、Treccani、RAE、Priberam、kotobank、Weblio；荷马、但丁、撒路斯提乌斯的出典抓原文核对。Perseus 网站对脚本返回 403，LSJ 改用 Logeion 查。
  - 同名产品和商标信号：网页搜索，加 Urban Dictionary、Justia 一类公开页面。Product Hunt 对脚本返回 403，没查成。
  - 命令撞名：本机 `command -v` / `which`，加各包注册表和 MCP 官方注册表。
- **词典没核实的候选不进细查。** 187 个候选里有 2 个（Kaimami、Ipdip）在词典里查不到对应词条，只列在 [§9](#9-全部候选)。
- **「空着」只表示查询时没被占用**，不保证能注册：GitHub 的 404 分不出没人用和被保留；App Store 的名字要建应用记录时才知道能不能用。
- **商标没有做正式检索。** 文中的「商标信号」只是公开页面上看到的申请、注册和使用情况，不构成法律判断。
- **域名不查可注册性。** 用户用自己的一级域名，不买域名；文中提到的 .com 只作「有没有别人在用这个名字」的同名信号。
- **推断与出处。** 事实尽量带出处；查不到的写「待核实」；靠常识或类比得出的写「推断」。中文用户怎么念、会叫它什么，都是推断，没有找真人试读。
- **评审方式。**
  1. 八个方向提候选：古希腊语、拉丁语与罗曼语、日语罗马音、其他语言、跨语言造词、少见的英语真词、从概念出发、从宣传页出发（[§9](#9-全部候选)）。
  2. 三位初筛评委（概念与宣传效果、独特与语言、中文用户）各打 1–5 分，也可以判「致命」。硬伤（撞名、负面义、中文谐音、神名或敏感名、和产品原则冲突、属于第一轮被否那一类）一票否决。表里的「初筛分」照录流程记分：三人分数相加，满分 15；部分被判致命的候选，流程记分低于三人之和（如 Yozhik、Omichle），扣分规则没有记录。
  3. 细查 20 个：正好是初筛分 10 分以上、没有被判致命的全部候选（11–12 分的 8 个，10 分的 12 个）。每个给绿灯、黄灯或红灯。
  4. 三位终评评委（概念与宣传效果；独特与长期；中文用户与传播）把细查过的 20 个和上一轮的四个名字放在一起，各排前 8，按 Borda 计票：第 1 名 8 分，依次减 1，第 8 名 1 分，三人相加，满分 24。文中的「票数」都指这个分数。
  5. 一位怀疑者复核票数前四名，试着推翻它们：重查词义、负面义、撞名和常见度，结论是「推翻」或「削弱」。这一轮四个都是「削弱」，没有被推翻的。
- **数量**：候选 187 个，和前两轮重复的 0 个，命令名不合格的 0 个，词典未核实 2 个；流程记录初筛后存活 135 个，细查 20 个。
- **一处执行偏差**：「其他语言」方向查询时 User-Agent 写的是 `name-research/1.0`，没有按任务说明带用户邮箱。那个方向的 Agent 给的理由是用户本人没说过要把邮箱放进第三方请求头。其余方向按说明执行。
- **只读。** 没有注册、购买，没有提交任何表单，也没有 star 或 fork。

<a id="0-推荐"></a>
## 0. 推荐

**推荐：Toedip，命令 `toedip`。** 终评票数第一（18 票）：概念与宣传效果评委排第一，独特与长期评委和中文用户与传播评委都排第四。怀疑者复核结论是「削弱」，没能推翻。

- 概念关联：英语习语 dip one's toe in 的意思是「试探着、第一次去碰某件事」（Wiktionary），Wiktionary 还单收了 toe-dip 词条，释义是「把一根脚趾伸进某物」。它直接回答用户卡住的那句「不知道从何开始」：不用跳进那一大堆，伸一根脚趾就算数。它落在「第一下 / 一小口」这一边，只说「这里可以进」，不说「还剩多少」，也不承诺把雾清掉。
- 宣传页：首屏标题不认识名字也成立，例如「Saved too much to know where to start? One toe is enough.」。画面现成：ASCII 鹭本来是涉禽，抬起一只脚，脚趾尖点进点阵雾，泛开一圈涟漪，涟漪中间露出一条视频里的那一秒。logo、贴纸、og 图都从这一个动作出来（[§7](#7-宣传页草案)）。
- 梗：「toedip 一下」＝先试一条；中文里「试水」「点水」「先试试水」「蜻蜓点水」是现成说法；两格表情可以反用「尴尬到脚趾抠地」：第一格脚趾抠地，第二格「不抠了，点一下」。
- 中文用户怎么叫：推断最可能叫「脚趾」（看 logo 起的外号，像 Yazi 被叫鸭子），其次「托迪」「试水」。首屏和 README 第一句要像 Deno 那样给读音 TOE-dip，否则会被拆成 to-e-dip、念成「托厄迪普」。
- 撞名和可用性：GitHub 裸名、`toedip-app`、`toediphq`、`toe-dip` 全空，Go 模块路径可以直接写 `github.com/toedip/toedip`；npm、PyPI、crates、Homebrew、Repology、MCP 官方注册表全空；App Store 中美区没有同名；同名仓库只有 5 个 0–1 星的零星项目；网页搜索没有同名产品或品牌（[§5](#5-可用性与撞名)）。toedip.com 2006 年已被人注册，用户不买域名，只作同名信号。
- 怀疑者复核：词义成立（toe、dip、dip one's toe in、toe-dip 都对得上，Urban Dictionary 的 toe dipper「先试水温的谨慎的人」可以交叉印证）。削弱的三点：Urban Dictionary 有拼写相近的零票性俚语，英语里 toe 也容易被往 camel toe、恋足方向开玩笑；小写 toedip 可能被误拆成 to-edip，里面藏着 oedip 这串字母；toedip.com 被占。

**有没有硬伤：查过，没有。** 下面几点都是宣传成本，不到换名的程度，各自有对策：

1. 名字里没有雾也没有点阵。它对上的是「从哪开始 → 一根脚趾」，不是地图本身；雾要靠画面和文案带出来。这是概念评委自己点出的弱点，也是它和 Fogdog 那类「只碰到雾的字面」相反的地方。
2. 拼写里藏着 Oedip（俄狄浦斯）。名字一律写全小写 `toedip`，官方文案不碰这个梗；HN、Product Hunt 标题要首字母大写，躲不开，评论区迟早有人玩。
3. 脚的联想。画面只用鹭的脚趾、ASCII 和涟漪，不放真人的脚。
4. 「试水」自带下一步。英语里 dip a toe in 后面常接 before diving in，文案不写 before you dive in，也不写「先试水再深入」，守住「一根脚趾就算数」。
5. 习语的透明合写，别人顺手也会起出这个名字（现有 5 个同名小仓库就是证据），护城河比造得更怪的名字浅。

**备选**（按票数）：

1. **Pertugio**（16 票，绿灯；怀疑者：削弱）：意大利语「小洞、开口」。但丁《地狱篇》第 34 歌第 138 行，但丁和维吉尔「per un pertugio tondo」（透过一个圆圆的小洞）看见天上的美好事物，下一行就是全篇最后一行「于是我们出来，重见群星」。雾不用散，一个小洞就够看见星星，宣传页首屏和 About the name 一句话讲完。命名空间是 20 个里最干净的：GitHub 裸名和后缀、所有包、App Store、MCP 全空，同名仓库 0，网上只有一家同名酒吧。独特与长期评委把它排第一。弱点：8 个字母到了上限，-gio 要标读音 per-TOO-jo；外号推断是「土鸡」（拼音拆读），要么主动认领成梗，要么就是硬伤，由用户拍板；把收藏比作地狱不合「东西在那儿歇着」的语气，文案不写「逃出来」；怀疑者查到一篇意大利科普文章把它列为借「洞」指女性性器官的词之一，主流词典没收，算轻度风险；它也可能被一眼归进第一轮那类「外语雅词」，区别在于它是具体名词，有一个洞、一个作者。
2. **Dokokara**（15 票，黄灯；怀疑者：削弱）：日语 どこから，「从哪儿？」。名字就是用户卡住时那句话，答案印在日本零食袋边上：从哪儿都能撕开。这项加工叫マジックカット，来历是一位专务在新干线上撕不开下酒的熏鱿鱼袋，只好干喝啤酒（ja.wikipedia「マジックカット」）。中文用户与传播评委排第一：「收藏了一堆不知道从哪开始？我做了个 dokokara」，名字和痛点标题是同一句话。拉丁字母写法在 GitHub、包、App Store 全空。弱点：8 个字母四个音节，命令偏长；名字是问句，单独出现时像在复述问题，旁边要跟答句；日区已有「どこから片付け？AI」用同一个词讲几乎同一件事（对象是房间）；日语假名搜索会被日常用法淹没；「こちら側のどこからでも切れます」这句包装原文待核实，名字去掉了 でも，是再创作；マジックカット 是注册商标，只能讲故事，不能借标识。
3. **Anazuri**（13 票，绿灯；怀疑者：削弱）：日语 穴釣り，冰钓、凿冰钓鱼。结冰的湖就是那一大堆收藏，不用把湖化开，只凿一个洞、垂一根线，「其余照旧冻着，没人说它欠着」；搜一句话跳到那一秒，就是线碰到鱼。占用和 Pertugio 一样干净（.com 也没注册）。弱点：拉丁写法对中文读者毫无提示，会被念成女性人名「安娜祖丽」；冰和雾是两套比喻；怀疑者补出两层冷僻负面义：古语 あなづり 是「侮り（轻视）」，隠語大辞典还收了一条明治以来的犯罪者隐语（在庙会上把女人钓上手）；它是日语词，用户对日语词的反感会不会波及日常词，要用户自己判断。这一轮没写它的宣传页草案。

**复查（2026-11-02，审稿时重跑）**：上面四个名字的 GitHub `users/<名>`、`users/<名>-app`、`users/<名>hq` 都是 404，npm `registry.npmjs.org/<名>` 都是 404；按仓库名搜索的数目是 Toedip 5、Pertugio 0、Dokokara 2、Anazuri 0，和 [§5](#5-可用性与撞名) 一致。词义重开词典核对：Wiktionary 的 [toe-dip](https://en.wiktionary.org/wiki/toe-dip)「To dip a toe into something」、[dip one's toe in](https://en.wiktionary.org/wiki/dip_one%27s_toe_in)「To explore or begin; to enter or get involved in tentatively and for the first time」，toedip 连写仍无词条；[pertugio](https://en.wiktionary.org/wiki/pertugio)「hole, opening」；[あなづり](https://en.wiktionary.org/wiki/%E3%81%82%E3%81%AA%E3%81%A5%E3%82%8A)「ice fishing」，Jisho 穴釣り 三义、非常用词；Jisho [何処（どこ）](https://jisho.org/search/%E4%BD%95%E5%87%A6)「where」、[から](https://jisho.org/search/%E3%81%8B%E3%82%89)「from」，都是常用词。和文中写法一致，没有改动。

**上一轮的四个名字：按第三版标准都排不进前 8，三位终评评委都没把它们列进自己的前 8，各 0 票。** 共同的问题是第 1 条「概念关联」：Guddle、Grepling、Butterbump 和雾、脑雾、「从哪开始」都没有关系；Fogdog 的本义（雾里的一块亮斑）其实碰到了「口子」，但它直接叫雾，又有加拿大商标和 Fogdog Sports 的历史，长期看最可能被迫改名。详见 [§8](#8-上一轮的四个名字)。

<a id="1-用户这次说了什么"></a>
## 1. 用户这次说了什么

用户 2026-11-02 讲概念的原话：

> 「然后就是整个概念层次上的，那个雾感觉有点脑雾的那种，因为就是你收藏了一大堆，但是却不知道从何开始去处理，出梳理，就感觉像这种去阻拦你」

讲起名要求的原话：

> 「然后英文尽量避免重复或者什么什么，用某种具体的有的单词，然后可以自造可以结合罗马音或者古希腊或者各种其他的，但是一定不要重复或者太常见，并且最好也跟我们整体上的有关联这种，甚至你宣传页很方便这种，主要是宣传效应吧」

**理解（推断，用户还没确认）：**

- 雾不是地图上的装饰，而是收了一大堆之后的脑雾：几百条视频、帖子、长文堆在那里，不知道从哪开始处理、梳理。雾挡在人和这堆东西之间，人干脆就不碰了。
- 产品不去驱散这团雾，改的是雾的意思：从「我欠着没处理的活」变成「东西在那儿歇着，等我想要哪条」。产品给的是一个进去的口子：从哪一片开始都行，搜一句话、点开一片或写下一句，那一片就清楚了；其余的留在雾里也没关系。产品不承诺把雾清空。
- 这和「不制造压力、没有未读数、没有未整理状态」不冲突：口子只说「这里可以进」，不说「还剩多少」。雾没有总量，没有进度条，也没有「已清除 37%」；打开一个口子，不会让别处的雾显得更欠债。
- 用户原话里的「处理」「梳理」描述的是他卡住的地方，不是产品的承诺。产品里算「梳理」的仍然只有两件事：让哪几片一直清楚，写下哪句话。所以名字和宣传只该落在「口子、线头、落脚点、第一下」这一边，不该落在「雾被清掉」那一边。
- 会冲突的说法：清空、清雾、全图点亮、处理完、整理完、收件箱归零、进度、完成率，以及「治好脑雾」「告别信息焦虑」。最后两种把产品说成了药，也承诺了产品做不到的事。

**起名要求，逐条：**

1. 只用拉丁字母的名字，不起正式中文名（延续 [调研 08](08-english-name.md)）。
2. 用某种语言里具体、真实存在的词，或者自造；可以结合日语罗马音、古希腊语或其他语言。
3. 一定不能和现有产品、项目重名，也不能太常见。
4. 最好和产品整体有关联：雾、脑雾、从哪开始、自己的判断。
5. 宣传页好做，主要看传播效果。

<a id="2-雾能给名字什么"></a>
## 2. 雾能给名字什么

**概念能落的点：**

| 落点 | 好处 | 风险 |
|---|---|---|
| 雾本身（脑雾） | 一眼对上点阵迷雾地图和用户自己的感受，画面现成。古希腊语 ἀχλύς（achlys）在荷马史诗里就是蒙住凡人眼睛的雾（Wikipedia「Achlys」）。 | 直接叫雾的词太常见、裸名早被占；Caligo、Sumu、Haar、Fogcat、Fogdog 前两轮已用过。名字等于问题本身，像在给脑雾代言。直接叫脑雾像医疗产品：日语 もやもや 正好是雾蒙蒙加心里不清爽，但 moyamoya 也是一种脑血管病（Wikipedia「Moyamoya disease」）。 |
| 雾散的一刻 / 放晴 | 宣传视频里雾散开那一下最抓人。 | 一说散就是在承诺清掉，会滑向全图、通关、进度；07 的 Unfog 就是因此被否（[调研 07 §7](07-positioning-and-naming.md#7-全部候选)）。只能做成动画，不能当名字。 |
| 雾里的一个口子 / 小孔 | 正是界面里发生的事：哪里都能缓缓张开一个洞，其余照旧是雾；只说「这里能进」。可借 ostiole（真菌放孢子、榕小蜂钻进无花果的小孔，Wiktionary）、peekaboo（作形容词指带孔、露出被遮住的东西，Wiktionary）。 | 「洞」在中英文里都容易滑向漏洞、loophole；口子本身抽象，要靠角色或动作撑。 |
| 线头 / 头绪 | 中文「理不出头绪」「找不到线头」就是用户说的卡住。日语 糸口（itoguchi）字面是线头，又指开端、线索（Jisho）。找到一个线头就行。 | 线团意象会把人带向「把整团理清」，回到梳理压力。Clew 在 07 已用过；阿里阿德涅的线团是神话名的坑。 |
| 落脚点 / 立足处 | 不承诺走完，只给一个能站的地方，和鹭单脚站在浅水里同一个画面。可借 toehold（只够放脚尖的落脚点，Wiktionary）、pou sto（阿基米德「给我一个立足点」，Wiktionary）、荷兰语 houvast、日语 手掛かり（Jisho）。 | 攀岩、摔跤（toehold 也是扳脚的招式）、合成生物学的 toehold switch 分走搜索；「立足」稍带励志腔。 |
| 渡口 / 浅滩 | 浅滩是鹭站的地方，也是不用游泳就能下水的地方。古希腊语 πόρος（poros）同时是「通道」和「渡口」（Wiktionary），反义词 aporia 就是「无路可走、不知如何下手」。 | 渡口隐含「要去对岸」，有终点；中文「渡」「津」容易滑回国风雅词；poros 和 aporia 被大量项目用了。 |
| 第一下 / 开个头 | 直接回应「不知道从哪开始」。可借拉丁语 incipit（文本开头的几个字，Wiktionary）、日语 切っ掛け（Jisho）、solvitur ambulando（「走起来就解决了」，常归给奥古斯丁，Wikipedia）。 | 「开始」类词是效率工具和鸡汤的常用词；祈使句（incipe「开始吧」）带催促；「开了头就完成一半」暗含进度。 |
| 雾里不动、一啄即中的鹭 | 角色和动作现成：鹭静止时清楚，动起来散成字符，一啄就是一个口子，对上「搜一句话跳到那一秒」。名字可以落在动作上。 | 鹭当吉祥物会让人想到宫崎骏的苍鹭（[调研 08 §7](08-english-name.md#7-全部候选) 已记）；crane 会被意译成鹤；Peck 在 07 已被否；「一啄即中」容易被读成效率。 |
| 选择瘫痪的寓言（布里丹的驴、芝诺） | 故事现成又有点荒诞。布里丹的驴站在两堆一样的干草中间选不出先吃哪堆，结果饿死（Wikipedia、Wiktionary「Buridan's ass」）；芝诺说要走到终点得先走一半……于是连第一步都迈不出（Wikipedia「Zeno's paradoxes」）。和「收了一大堆，不知从何下手」同构。 | 名字会是人名或悖论名，像掉书袋；角色要换成驴，英文 ass 自带粗口梗；「饿死」在文案里要处理得轻。 |

**前两轮的教训：**

- 第一轮的日语美学词（Yohaku、Mitate、Shakkei、Kodawari、Mekiki、Yoin、Omomi）和拉丁文雅词（Cerno、Legere、Punctum、Placet、Stet）是同一类：从一门文化里借来讲品味、判断、意境的抽象名词。它们没有能画出来的东西，也没有私人、具体的来历，换给任何一个笔记或阅读工具都能用，所以「好听但没有作者」（[调研 08 §1](08-english-name.md#1-思鹭为什么不行)）。这和国风中文名的模板是同一个毛病，只是换了语种。
- 用户这次明确说可以用罗马音和古希腊语，可见他讨厌的不是外语，而是词的类型。能用的外语词是具体的日常词、实物词、动作词，或者带一个具体、有点荒诞的小故事的词；不能用的是讲修养、审美、品格的概念词。判断方法：这个词能不能画成一个 ASCII 小图，能不能用一句不严肃的话讲完来历。
- 第一轮的中英对音（思鹭 / Seelu 等）让英文名寄生在中文名上；Seelu 还撞上思源，又会被读成死路、SiLU、loo。这一轮仍然只用拉丁字母的名字。
- 第一轮把「体现定位」排在标准第一条（[调研 07 §3](07-positioning-and-naming.md#3-命名标准)），选出来的多是要先讲一段含义才成立的解释型名字。第二轮反过来，写明「不要求名字直接表达定位」（[调研 08 §3](08-english-name.md#3-命名标准第二版)），按「名字就是角色」去找。用户对第二轮没表态，回来讲雾的概念。推断：只有角色和梗、离概念远是不够的，第三版两头都要占。
- 第二轮里和雾直接相关的名字（Fogdog、Caligo、Haar、Dimma、Nebulo）多半只碰到「雾」的字面，没碰到「不知从何开始、给你一个口子」这一层。
- 前两轮被否的共同原因：蹭（思鹭撞思源）、被误解（死路、SiLU、loo；Spoony、Shypoke 一查词源就有问题）、常用词搜不到也拿不到裸名、像 AI 创业公司或效率工具、NPC 感。
- 可用性的规律：4–7 个字母的真词，GitHub 裸名几乎都被早年的闲置账号占着（这一轮的种子 achlys、itoguchi、tegakari、kikkake、polepole、toehold 都是）。前两轮的红灯多出在同名命令和同名包上。所以拿不到裸名不必一票否决，可以用 `<名字>hq`；同名命令和同类目的同名产品才是硬伤。

**宣传效果的规律：**

- 名字解释有四种放法：①首句括号一次说完（Yazi：means "duck"）；②README 靠后单设一节，首句名字挂页内链接（Zellij「Origin of the Name」、Karakeep「About the name」）；③首屏完全不提，名字只当标签（Ghostty、Ollama、Immich、Kagi、Obsidian、Bun）；④首句只给读音不给含义（Deno）。样本里没有一个项目把名字解释放进首屏标题。
- 首屏标题几乎都是「类别 + 一个形容或承诺」，名字不参与标题句。标题必须能在不认识名字的情况下成立，名字只要不和标题打架就行。
- 最省力的情况是名字和首屏画面是同一样东西：Ghostty→幽灵、Deno→恐龙、Atuin→乌龟、Ollama→羊驼、Obsidian→刀刃对应 Sharpen、Zellij→拼花瓷砖对应分格面板。名字能画出来，logo、贴纸、og 图就都有了；LocalSend 名字最好懂，却没有可画的东西。
- 外语真词或造词变成加分（揭晓即彩蛋）的条件：有一个具体、可画的实物；含义和产品体验有一层会心一笑的对应（Karakeep 的「舍不得扔的杂物」对应收藏者）；解释一两句讲完；不读解释也不妨碍理解首屏。缺一条就容易变负担。
- 变成负担的情况：拼写不能从读音推出（Zellij 常被问怎么读）；含义需要文化背景、首屏又没别的抓手；名字是常用词，搜索撞车（Warp、Obsidian、lazy）；名字蹭别人（Postwoman 蹭 Postman）最终要改名。
- 常用英文词的风险在 Karakeep 上很具体：旧名 Hoarder 因商标纠纷被迫改名（2025 年 4 月，出处是维护者公告的转载）。改名后选了真实外语词并配一段有画面的解释，改名本身变成一次传播。
- 名字能直接进句子当命令或宾语，文案最好写：bun run、all in Bun；全小写 ASCII 名字当命令时，首屏的代码块本身就是广告。
- 语气可以由名字承担：tldraw 全小写加 very good free whiteboard 的自谦，lazygit 的 Rant time，Karakeep 自嘲「你就是个囤积癖」。
- 中文用户这一层：拼音名直接成梗（Yazi=鸭子），真实英文词会被直译成中文名（Obsidian=黑曜石），官方中文页一般保留拉丁名、只译副标题（LocalSend、Obsidian）。名字最好让中文用户一眼起出外号，外号就是中文平台上的传播名。

**「宣传页很方便」检查清单：**

1. 不解释名字，也能写出一句成立的首屏标题（类别 + 承诺）。
2. 名字能直接画成一个具体的东西（动物、物件、地形），能拿来做 logo、贴纸、og 图。
3. 名字和产品主画面（雾 / 脑雾 / 入口）是同一样东西或有一层对应，揭晓含义时能让人会心一笑。
4. 名字的解释能在一句话内讲完，不需要文化背景课。
5. 口头说一遍对方能拼对，看一眼拼写对方能读对（必要时首句给读音，像 Deno）。
6. 名字全小写能直接当命令，放进句子里读得通（「xxx 一下」「打开 xxx」）。
7. 中文用户能一眼给它起出外号，外号不歧义、不土。
8. 搜「<名字> app」和「<名字> github」第一页没有别的同名产品或项目。
9. 名字不是常用英文词，也不是在别人名字上做文字游戏（避开 Hoarder、Postwoman 式的改名风险）。
10. 名字能直接当话题标签或帖子标题里的专名用（「#<名字>」「用 <名字> 收拾我的收藏夹」）。
11. 名字不和「知识库 / 第二大脑 / 待办」这类类别词撞车。
12. README 里能单独写一小节「About the name」，三五句讲完，并顺带讲清产品理念（雾不需要全清掉）。

**中文平台怎么介绍英文名的软件：**

- **V2EX**（有数据）：2026-11-02 抓取「分享创造」节点 60 条标题，28 条以「做了个 / 写了个 / 开源了 / 复刻 / 折腾」开头，只有 11 条以拉丁字母名字开头。常见形状是「做了个 X：一句中文说明」，名字放在句中或句尾，经常中英成对（「影迹 PhotoTrace」「AudioScript 声稿」）。名字的作用是点进去之后被记住，吸引点击的是痛点和「我做了」的口吻（v2ex.com/go/create）。
- **少数派**：自荐文先写痛点、名字后置，借大家认识的产品当锚点，如「为了解决Obsidian的分享难题，我做了一个一劳永逸的插件【自荐】」（sspai.com/post/102485）。
- **B站**：「名字-功能【开源免费软件】」或情绪钩子开头，如「LocalSend-局域网快速互传文件【开源免费软件】」（BV13w411X7oa）、「断网也能传！电脑手机互传开源软件LocalSend」（BV1dhahz5Ep1）。名字自解释时进标题；陌生造词常被「神器 / 平替 / 三款工具」替代。首图是界面截图加大字（推断，未逐个核实）。
- **即刻**：「cleanMyMac的开源平替 Pearcleaner」，即「知名产品的开源平替 + 名字」；改名本身也会被拿来发帖。
- **小红书、视频号**：这次抓不到，待核实。推断更偏「神器 / 平替 / 我做了」加大字封面，英文名多出现在封面小字或正文里，外号比原名更常见。
- **外号**：真实英文词会被直译（Obsidian→黑曜石），拼音名直接读成中文（Yazi→鸭子）；Ollama「羊驼」、Ghostty「小幽灵」这类说法没找到可靠出处，待核实。

对本产品的含义（推断）：中文平台上，标题靠「收藏了一堆不知道从哪开始？我做了个…」这样的痛点句起量，英文名只要在封面小字里好看、在正文里一眼能读、能自然生出一个中文外号；名字不必承担解释产品的任务。

<a id="3-命名标准第三版"></a>
## 3. 命名标准（第三版）

按用户这次的口味排序。上一版见 [调研 08 §3](08-english-name.md#3-命名标准第二版)。

1. **概念关联，宣传好做。** 名字落在雾这个概念的某一个点上（口子、线头、落脚点、第一下、鹭的一啄、选择瘫痪的寓言），能一句话写出宣传页首屏标题；这句话不承诺清掉雾，也不说「处理完」。
2. **不撞名，不常见。** 同类目（笔记、稍后读、收藏、AI 记忆、效率工具）没有同名产品；npm、PyPI、crates、Homebrew 和各发行版没有同名的活跃包或命令；不是常用英文词。GitHub 裸名最好，拿不到时 `<名字>hq` 也行。
3. **真实可核实，或者造得干净。** 真词要有词典出处，故事也要有出处；造词要能拆成两半，每一半都说得清来源，而且只有一种读法。
4. **有梗，有作者。** 指向一个具体、能画成 ASCII 的东西或动作，或者带一个有点荒诞的小故事；不是讲品味、修养、意境的抽象词。能长出一个动词（「X 一下」）和一个角色。
5. **中英都好念。** 英文读者第一眼念得出；中文用户能用两三个汉字标音，近音里没有负面字；以两三个音节为主。
6. **当标识好看。** 全小写 ASCII，没有连字符和数字，不超过 8 个字母，6 个左右最好；当命令、`.<名字>/`、`<NAME>_`、`<名字>://`、`<名字>-plugin` 都不难看。
7. **不制造压力。** 名字和它自然引出的说法里，没有清空、处理完、进度、完成、治好、未读这类意思，也不是催人开始的祈使句。
8. **不被误解。** 查过病名和医疗词、英文俚语、AI/ML 术语、主要外语里的负面义，以及中文近音。

**常见的坑：**

- **直接叫雾**：fog、mist、haze、nebula 和它们的外语说法（Caligo、Sumu、Haar、Dimma、Nebulo 前两轮已否）。常见、被占，还把产品等同于问题本身。
- **把脑雾当病**：brain fog、clarity、cure、heal、cognitive，还有日语 moyamoya（烟雾病，Wikipedia）。名字一沾病就像健康产品，还暗示能「治好」。
- **清雾和通关**：clear、unfog、sweep、zero、done、declutter、点亮全图。和「不制造压力」正面冲突。
- **开始类的鸡汤和祈使句**：start、begin、kickoff、momentum、「万事开头难」、拉丁语 incipe。
- **把「梳理」当承诺**：organize、sort、tidy、untangle；08 的 Tildy 就是因为像整理工具被否的。
- **以「一大堆」为主题**：pile、stack、hoard，还有 tsundoku（積ん読）：GitHub 已有 314 个同名仓库，npm、PyPI 都被占（2026-11-02 查）。
- **换了语种的雅词**：kairos、aletheia、eudaimonia、wabi、yohaku，和国风中文名一个毛病。
- **神话名和哲学名词**：Ariadne、Achlys（当女神讲时是愁苦、死亡之雾，Wikipedia）、aporia、epoché。可以写文案，不宜当名字。
- **外语里的负面义**：每个外语词都查几种主要语言。例：pousto 对应保加利亚语、俄语 пусто「空」，现代希腊语近形 πούστης 是脏话；07 的 Sumu 在斯瓦希里语里是毒药。
- **要讲两层才成立**：先讲语法、再讲典故，名字才有意思，宣传页放不下。
- **难拼**：双写辅音（kikkake）、超过 8 个字母（hitokuchi）、读法不定的 ou / ow（houvast）。
- **蹭别人的角色或品牌**：鹭会让人想到宫崎骏的苍鹭；peekaboo 式造词要避开同名产品；-tty、grep- 前两轮已用过（Capytty、Grepling）。

<a id="4-入围名单"></a>
## 4. 入围名单

入围的是终评票数前 8 名（Dotford 和 Plodge 同为 11 票）。上一轮的四个名字和本轮其余 12 个细查名都没排进前 8，列在本节末尾的总表里。可用性明细见 [§5](#5-可用性与撞名)，词义和同名产品见 [§6](#6-词义核实与同名产品)。上一轮的入围名单见 [调研 08 §4](08-english-name.md#4-入围名单)。

**Toedip**：命令 `toedip`；跨语言造词方向；18 票，绿灯，推荐。

- 语言与原文：英语 toe + dip，取自习语 dip one's toe in。
- 字面：伸一根脚趾进去试水。dip one's toe in =「试探着、第一次去碰某件事」；Wiktionary 另有 toe-dip 词条，「把一根脚趾伸进某物」。
- 概念关联：不用跳进那一大堆，伸一根脚趾就算数；试水不承诺游完。落在「第一下 / 一小口」。
- 首屏标题：Saved too much to know where to start? One toe is enough.
- 角色：鹭抬起一只脚，脚趾尖点进点阵雾，泛开一圈涟漪，涟漪中间露出一条视频里的那一秒。
- 梗：「toedip 一下」＝先试一条；话题 #toedip；贴纸是一根鹭的脚趾加一圈涟漪；反用「尴尬到脚趾抠地」。
- 中文怎么念和叫：英文 /ˈtoʊdɪp/，近「托迪普」；照拼音拆成 to-e-dip 会念「托厄迪普」，所以首句要给读音 TOE-dip。外号推断是「脚趾」「试水」「点水」。
- 风险：名字里没有雾；拼写里藏着 Oedip；脚的联想和零票性俚语；「试水」暗示之后要深入；dip 在金融（buy the dip）、美甲（dip powder）、俚语（溜了）里另有意思，会分走搜索；toedip.com 2006 年已被注册。
- 评委怎么看：初筛 10 分（概念 4、语言 3、中文 3）。终评：概念与宣传效果评委排第一，说它传播门槛最低、首屏不用解释、命名空间全绿，如果用户更看重梗和故事，第二选择是 Dokokara；独特与长期评委排第四，说它是常见习语的透明合写，别人顺手也会起出来，护城河比 Pertugio、Dotford 浅；中文用户与传播评委排第四，说外号意思都正面，但中文用户不知道怎么断，脚趾会被拿来开足控和「脚趾抠地」的玩笑。
- 票数：18（8 + 5 + 5）。怀疑者：削弱。

**Pertugio**：命令 `pertugio`；拉丁语与罗曼语方向；16 票，绿灯，备选第一。

- 语言与原文：意大利语 pertugio，重音 pertùgio。
- 字面：小洞、开口（Wiktionary、Treccani）。出处：《地狱篇》第 34 歌第 138 行「per un pertugio tondo」，下一行是全篇最后一行「E quindi uscimmo a riveder le stelle」（于是我们出来，重见群星），已对照 it.wikisource 原文。
- 概念关联：雾不用散，一个圆圆的小洞就够看见星星；它只说「这里能看出去」，不说还有多少暗处。但丁走出最黑的地方，靠的也不是把黑暗清掉，而是找到一个洞。
- 首屏标题：A quiet map of everything you saved. One small opening is enough.
- 角色：鹭从一个 ASCII 圆洞 ( ) 里探出头，洞外是几颗点阵星星 `* . *`；鹭静止时清楚，钻洞的一瞬散成字符。
- 梗：「pertugio 一下」＝在雾里开个小洞看一眼；贴纸「圆洞 + 星星」；About the name 一句话讲完。
- 中文怎么念和叫：宣传页写 per-TOO-jo；中文用户多半照拼写读「佩图吉奥」。外号推断是「土鸡」（拼音拆读成「佩土鸡哦」），认真介绍时意译成「小洞」。
- 风险：8 个字母到上限；-gio 要标读音，口头会被拼成 pertujo、pertuggio，搜索引擎会纠成 Perugia、pugio；「土鸡」外号；把收藏比作地狱；有一篇意大利科普文章把它列为借「洞」指女性性器官的词之一，主流词典没收；可能被归进「外语雅词」；pertugio.com 2023 年被人注册，用途不明。
- 评委怎么看：初筛 11 分（4、4、3）。终评：独特与长期评委排第一，理由是真实词、出处对过原文、各命名空间零占用三件事叠在一起，五年内被抢成同类产品的概率低；概念与宣传效果评委排第五，说来历最动人，但把收藏比作地狱，又要上一节但丁课，适合写进文案，当名字偏重；中文用户与传播评委排第五，说读不准、外号长不出来。
- 票数：16（4 + 8 + 4）。怀疑者：削弱。

**Dokokara**：命令 `dokokara`；从概念出发方向；15 票，黄灯，备选第二。

- 语言与原文：日语罗马音 どこから（何処から）。
- 字面：どこ（哪里）+ から（从），「从哪儿？」。两部分经 Jisho、Wiktionary 核实；短语本身没有单独词条。来历：日本零食袋边上「从哪儿都能撕开」的加工叫マジックカット，起因是旭化成ポリフレックス的专务出差回程在新干线上撕不开熏鱿鱼袋，只好干喝啤酒，回去问技术人员「指先で簡単にどこからでも破れる袋はつくれないか」，1987 年取得专利（ja.wikipedia「マジックカット」）。
- 概念关联：名字是用户卡住时那句「从哪儿开始？」，答案是 どこからでも（从哪儿都行）。雾＝那一袋撕不开的东西，产品＝那道哪儿都能撕的切口；撕开一角就能吃，剩下的照样封着。
- 首屏标题：Your saves tear open from any side.（宣传页草案改成了 Saved hundreds of things? Open them from any corner.，见 [§7](#7-宣传页草案)）
- 角色：一只点阵零食袋，袋边一排更亮的小点；鹭在任意一个点上撕开一小角，袋口飘出几个字符。
- 梗：「从哪儿撕都行」；「Dokokara? Dokokara demo.」；日本网友吐槽「どこからでも切れない」的梗可以自嘲接住（推断，未核实是否常见）。
- 中文怎么念和叫：「多可卡拉」「多口卡拉」，四个音节；看日漫的人认得 doko。外号推断是「零食袋」「doko」「从哪儿」；「卡拉」会带出卡拉 OK。
- 风险：8 个字母四音节；名字是问句，单独出现时像在复述问题；日区「どこから片付け？AI」讲几乎同一件事；假名在日语里是天天用的短语，搜索会被淹没；包装原句「こちら側のどこからでも切れます」待核实；マジックカット 是注册商标；「撕」在中文网络有「开撕」义。
- 评委怎么看：初筛 11 分（4、4、3）。终评：中文用户与传播评委排第一，说名字、痛点和中文平台的标题句式是同一句话，零食袋撕口中文用户也天天见；概念与宣传效果评委排第二，说梗最足、最像独立开发者的作品，扣在长度和日区同名应用；独特与长期评委没把它排进前 8。
- 票数：15（7 + 0 + 8）。怀疑者：削弱。

**Anazuri**：命令 `anazuri`；从概念出发方向；13 票，绿灯，备选第三。

- 语言与原文：日语罗马音 穴釣り（あなづり）。
- 字面：穴（洞）+ 釣り（钓）。Jisho 三义：在岩缝、消波块缝隙里垂钓；冰钓（尤指钓公鱼）；把饵钩伸进洞里钓鳗。Wiktionary、kotobank、Weblio 交叉核实。
- 概念关联：结冰的湖就是那一大堆收藏，不用把湖化开，只凿一个洞、垂一根线；其余照旧冻着，没人说它欠着。搜一句话跳到那一秒，就是线碰到那条鱼。
- 首屏标题：One small hole in the ice. The rest of the lake can stay frozen.
- 角色：鹭围着小围巾站在点阵冰面上，面前一个圆洞，垂一根线；鱼上钩时鹭一动就散成字符。
- 梗：「凿个洞钓一下」；话题 #冰钓我的收藏夹 #只凿一个洞；贴纸是鹭在冰洞前打盹、钓上来一条视频形状的鱼。
- 中文怎么念和叫：「阿纳祖里」「安娜祖丽」，像女性人名；看到汉字的会说「穴钓」「冰钓」。
- 风险：要一句解释；冰和雾是两套比喻；古语 あなづり 是「侮り（轻视）」；隠語大辞典有一条明治以来的犯罪者隐语；搜索引擎会纠成 Ananuri（格鲁吉亚古堡）；Jisho 标为非常用词；是日语词。
- 评委怎么看：初筛 10 分（4、3、3）。终评：独特与长期评委排第二，说占用和 Pertugio 一样干净，画面具体，也不承诺把冰化完；概念与宣传效果评委排第三，说画面和概念对得最漂亮，扣在拉丁字母形对中文读者毫无提示；中文用户与传播评委没排进前 8。
- 票数：13（6 + 7 + 0）。怀疑者：削弱。

**Dotford**：命令 `dotford`；跨语言造词方向；11 票，绿灯。

- 语言与原文：英语 dot + ford，仿英国地名 -ford。
- 字面：dot 小圆点；ford 是河水浅、河底站得稳、不用桥就能蹚过去的地方（Wiktionary）。拼起来是「点阵里的浅滩」，读着像英国小镇。
- 概念关联：只说这里水浅、脚下站得住，不承诺渡完整条河。落在「落脚点」。
- 首屏标题：A shallow place to step into everything you saved.
- 角色：鹭单脚站在一片由点组成的浅水里，旁边一块路牌：DOTFORD, pop. 1。
- 梗：「去 Dotford 蹚一蹚」；路牌贴纸「Welcome to Dotford」；照 Oxford＝牛津译成「点津」，「点津大学」的自嘲。
- 中文怎么念和叫：「多特福德」，四个音节偏长；可能被叫「点福特」「多福」（粤语近「多福」，偏俗）。
- 风险：含义要靠拆词才懂，揭晓前像个普通地名；英文搜索会被纠成 Dartford、Deptford；名字含 Ford（驰名商标），因为是地名后缀，冲突概率低（推断）；「津」靠近国风渡口雅词；浅滩暗含有对岸。
- 评委怎么看：初筛 10 分（4、3、3）。终评：独特与长期评委排第三，说它是自造词，长期最不怕撞；概念与宣传效果评委排第四，说有作者味、梗多，扣在搜索被纠错。中文用户与传播评委没排进前 8。
- 票数：11（5 + 6 + 0）。

**Plodge**：命令 `plodge`；少见的英语真词方向；11 票，绿灯。

- 语言与原文：英格兰东北部方言（Geordie、Wearside）plodge。
- 字面：在海边、水洼或泥里蹚水、扑腾（Wiktionary，参考 New Geordie Dictionary）；另一个同形词是牛津剑桥俚语「门房」。
- 概念关联：不用游过整片水，在浅处蹚两步就行；鹭本来就在浅水里蹚着找吃的。脚湿了就算开始，其余的水不用管。
- 首屏标题：Everything you saved, on one local map. Wade in anywhere.
- 角色：鹭像卷起了裤腿，一抬脚溅起几个点阵水点；动快了，水点和鹭一起散成字符。
- 梗：「plodge 一下」；中文直接叫「扑腾」，「先扑腾一下」「在收藏夹里扑腾两下」。
- 中文怎么念和叫：单音节 /plɒdʒ/，中文用户多半念「普拉吉」「普洛奇」，或误读成 pledge、plunge。外号推断是「扑腾」，音近义近。
- 风险：拼写到读音没有直观路径；字形贴近 plod（苦干、步履沉重，英国俚语里还指警察）、pledge、lodge，英文第一印象偏「苦差事」；「瞎扑腾」在中文里略带贬义；plodge.com 在 Afternic 挂牌。
- 评委怎么看：初筛 10 分（3、4、3）。终评：中文用户与传播评委排第三，说外号最像独立开发者的口气；独特与长期评委排第六；概念与宣传效果评委排第七，扣在 plod 带来的「苦差事」印象和产品要的松弛感拧着。
- 票数：11（2 + 3 + 6）。

**Stikla**：命令 `stikla`；其他语言方向；10 票，黄灯。

- 语言与原文：冰岛语 stikla。
- 字面：名词「踏脚石」，现代也指预告片；动词「像踩踏脚石那样走」；成语 stikla á stóru 字面「踩在大石头上」，意思是「只讲要点」（Wiktionary、BÍN）。
- 概念关联：一大堆收藏像一条看不清的河，不用游过去，只踩露出水面的几块石头；成语「只挑大石头踩」对上「让哪几片一直清楚」。石头没有「还剩几块」。
- 首屏标题：Your saved videos and posts, on your own disk. You only need the stones you step on.
- 角色：鹭单脚站在一块 ASCII 石头上，跳向另一块时散成字符，落稳了再聚回来。
- 梗：「stikla 一下」；「今天只 stikla 了两块」；预告片义也能借：每条收藏有一段自己的 stikla。
- 中文怎么念和叫：「斯提克拉」，6 个字母、两个重读音节；中文锚点是「摸着石头过河」，宣传页可以写「不用过河，踩一块就行」。外号推断是「斯提」「石头」，或因像 sticker 被叫「贴纸」。
- 风险：GitHub 裸名在一个活跃个人号手里；英文读者会看成 stickler（较真的人），和「不制造压力」反着；冰岛语里是「预告片」的日常词，拉脱维亚语是「玻璃的」，搜索会被淹没；stikla.com 在域名投资方手里（推断）。
- 评委怎么看：初筛 11 分（4、4、3）。终评：中文用户与传播评委排第二，说念起来最省事、没有负面近音；概念与宣传效果评委排第六，扣在冰岛语读者之外没人知道它是什么；独特与长期评委没排进前 8。
- 票数：10（3 + 0 + 7）。

**Carptim**：命令 `carptim`；拉丁语与罗曼语方向；6 票，绿灯。

- 语言与原文：拉丁语副词 carptim，来自 carpō「摘、采」（carpe diem 的 carpe）。
- 字面：一块一块地、挑着来、东一处西一处（Wiktionary、Lewis & Short）。出处：撒路斯提乌斯《喀提林阴谋》4.2，他决定把罗马人民的事迹 carptim 写下来，只写在他看来值得记住的那些片段（已对照 thelatinlibrary 原文）。
- 概念关联：不用从头写到尾，挑在你看来值得的那几块；它说的是「挑」，不是「清」，正对产品里算判断的两件事。
- 首屏标题：Everything you saved stays on your disk. Pick up whichever piece you want.
- 角色：鹭叼着一条 ASCII 小鲤鱼 `><>`（carp 是鲤鱼），只叼一条，池里其余的鱼照旧游。
- 梗：「carptim 一下」；carp + tim 读着像 carp time；中文外号「鲤鱼」「锦鲤」。
- 中文怎么念和叫：「卡普提姆」「卡普汀」，r-p-t 连写口头难拼。
- 风险：英语 carp 又是「挑刺、抱怨」，字母一换就是 crap；「锦鲤」会把产品带向转运玄学；是拉丁词，正落在第一轮被否的那一类；名字是副词，长不出自然的「X 一下」。
- 评委怎么看：初筛 10 分（4、3、3）。三位终评评委都把它放在第六到第八：都承认出处有作者，也都担心「拉丁雅词」的嫌疑。

## 6. 词义核实与同名产品

入围的 8 个名字。只有前四名做了怀疑者复核。上一轮的同类内容见 [调研 08 §6](08-english-name.md#6-词义中文读法与同名产品)。

**Toedip**

- 原语言词义复核：合写的 toedip 是自造连写，Wiktionary 没有词条；组成部分都核实过：[toe](https://en.wiktionary.org/wiki/toe)（脚趾）、[dip](https://en.wiktionary.org/wiki/dip)（短暂浸入液体；放入液体中）、[dip one's toe in](https://en.wiktionary.org/wiki/dip_one%27s_toe_in)（「试探着、第一次去碰某件事」）、[toe-dip](https://en.wiktionary.org/wiki/toe-dip)（「把一根脚趾伸进某物」）。toe-dip 比喻义的书证（Max Gunther 的两本书、2018 年 Rewire 的报道）都是「浅浅试一下、还没真下水」，Gunther 还拿它和 waded、plunged 排成由浅到深。
- 现代用法和俚语：Urban Dictionary 没有 toedip 精确词条；toe dipper =「做事谨慎的人」「怕水先用脚趾试水温的人」；toe dipping = 点到为止的调情；模糊匹配有 Talladega Toe Dip、toedigger 等性俚语，都是 0 票。dip 单用另有「笨蛋、扒手、口含鼻烟、溜了」等俚语义，合写后基本不会这样读（推断）。冰壶运动里 toe dip 是鞋尖涂层的通用叫法。英语里 toe 沾一些性语境（camel toe、Wiktionary 标为 slang 的 toe job），用脚趾当品牌形象可能被往恋足方向开玩笑（推断）。
- 其他语言同形词：Wiktionary 精确拼写在任何语言都没有词条。荷兰语、南非语 toe =「关上、那时」，荷兰语 dip =「短暂的低落」，荷兰读者可能读出「一阵小低落」（推断，轻微）。日语、西语、德语、法语没有同形词；韩语、现代希腊语待核实。
- 中文读法与谐音：「托迪普」「头滴普」，粤语近「拖碟」；可能和 TOEIC 混；「托」在中文网络有「托儿」义，影响小。没有明显不雅谐音（推断）。

## 7. 宣传页草案

票数前三名各一组。所有首屏标题都过了一遍第 7 条：不出现 clear、all done、zero、finally、catch up，不用 Start 开头的祈使句，不说「还剩多少」。产品界面里的文案按项目约定用「收下 / 存着 / 回头看」；下面平台标题里的「收藏」是用户卡住时自己的说法，用来对上痛点。命令示例里的子命令都是草拟，产品还没有 CLI 规格；获取插件组织名见 [§10](#10-获取插件组织的名字)。

**Toedip**

- 首屏标题（英）：Everything you saved from your feeds, on your own computer. Any one of them is a way in; the rest can stay in the fog.
- 首屏标题（中）：各平台收下的东西，都存在你自己电脑上。从哪一条都能进去，其余的留在雾里也没关系。
- 副标题（英）：Keep your own line of thought, outside the feed. Speech and on-screen text become searchable, so one sentence lands on the second a video said it.
- 副标题（中）：在推荐流外，维护一套你自己的思路。口播和图里的字都能搜，搜一句话，就落到视频里说出它的那一秒。
- 首屏画面：
  1. 整屏是均匀的灰阶点阵雾，点在原地慢慢漂，没有标题、数字或计数。
  2. ASCII 鹭从右侧走进来，走得快时身体散成一串字符拖在身后；停下后字符收拢，单脚站在雾里。
  3. 鹭抬起另一只脚，停一拍（就是「不知道从哪下手」的那一下），然后用脚趾尖点进雾里随便一处：那里泛出一圈同心涟漪，回落后空出一小块清楚的地方，露出一条视频的那一秒：一帧画面、一行字幕、时间戳 03:41、标签「机器转写」。
  4. 涟漪张到一个小圆就停，其余的雾一点没变淡，没有进度条，也不留「已看过」的痕迹。
  5. 标题在雾上方淡入；左上角写全小写的 toedip，图形是一根鹭的脚趾加一圈涟漪。
  6. 交互：在任意位置点一下，鹭走过去点一下，开出另一个小口子；之前的口子过几秒慢慢合回雾里，被按住的那片一直清楚，旁边是用户写下的一句话。
  7. 减少动态效果时只放一帧：鹭单脚站着，脚趾下一圈静止的涟漪。og 图用第 3 步定格的那一帧。画面里一律不出现人的脚。
- 名字解释：toedip（读作 TOE-dip）出自英语 toe-dip：伸一根脚趾进水里试一下，也就是 dip a toe in，第一次、试探着碰一碰（Wiktionary）。
- README 开头（英）：

  ```markdown
  # toedip

  Everything you saved from your feeds, on your own computer. Any one of them is a way in; the rest can stay in the fog.

  toedip (TOE-dip, as in "dip a toe in") keeps what you saved on Douyin, Xiaohongshu, Bilibili, WeChat and X as plain files in a folder. Speech and on-screen text become searchable, so a sentence takes you to the second it was said. Nothing is counted and nothing is unread.
  ```

- README 开头（中）：

  ```markdown
  # toedip

  各平台收下的东西，都存在你自己电脑上。从哪一条都能进去，其余的留在雾里也没关系。

  toedip（读作 TOE-dip，取自英语 dip a toe in：伸一根脚趾试试水）把你在抖音、小红书、B站、公众号、X 上收下的内容，存成一个目录里的普通文件。口播和图里的字都能搜，搜一句话就落到视频里说出它的那一秒。不计数，也没有未读。
  ```

- 各平台标题：
  - HN：Show HN: Toedip – your saved videos as local files, searchable to the second
  - Product Hunt：Your saves on your own disk. One toe in is enough.
  - V2EX：[分享创造] 做了个开源的 toedip：各平台收藏存成本地文件，搜一句话跳到视频里说它的那一秒
  - 小红书：收藏了几百条不知道从哪开始？伸一根脚趾就够了（开源工具）
  - 即刻：做了个开源小工具 toedip：收藏的一大堆就让它雾着，伸一根脚趾进去就算数
- 命令示例：

  ```console
  $ toedip plugin add github.com/rockpoolers/bilibili
  $ toedip search "番茄炒蛋先炒蛋"
    bili/BV1…  01:12  …番茄炒蛋先炒蛋，盛出来再下番茄…   [机器转写]
  $ toedip keep bili/BV1…          # 这一片一直清楚
  $ toedip note bili/BV1… "其实我只想学这一步"
    → ~/.toedip/items/bili-BV1…/note.md
  ```

- 外号：推断最可能叫「脚趾」（看 logo 和贴纸起的，像 Yazi 被叫鸭子）；其次懂英文的人叫「托迪」，聊用法时说「试水」「toedip 一下」。
- 贴纸点子：两格表情，第一格一排 ASCII 脚趾在抠地，配字「收藏太多，脚趾抠出三室一厅」；第二格鹭单脚站着，只伸一根脚趾点出一圈涟漪 `( ( · ) )`，配字「不抠了，点一下」。单图版：一根鹭的脚趾加一圈涟漪，下面一行「toedip 一下」。
- 宣传风险：
  1. 拼读会走样，首屏和 README 第一句给读音 TOE-dip。
  2. 拼写里藏着 Oedip（巧的是 Oedipus 的希腊语原义正是「肿脚」，Wikipedia）；官方文案不碰，名字一律小写，但 HN、Product Hunt 标题要首字母大写，躲不开。
  3. 脚的联想：画面只用鹭的脚趾、ASCII 和涟漪；「脚趾」外号可能被嫌土；「脚趾抠地」带来的是尴尬，不是轻松，只用在表情里。
  4. 名字可能显得胆小或像新手教程（devICT 的 Toedipper 就是新手入门系列）。
  5. 「试水」自带下一步：不写 before you dive in；「先 toedip 一下」留给用户自己说，产品自己的文案不用祈使句催人。
  6. dip 的其他意思（buy the dip、溜了、蘸酱、美甲 dip powder）会分走搜索。
  7. 鹭仍会让人想到宫崎骏的苍鹭。

**Pertugio**

- 首屏标题（英）：Your saved videos and posts, on your own computer. Any spot is a way in.
- 首屏标题（中）：收下的视频和帖子，都在你自己的电脑上。从哪儿看起都行。
- 副标题（英）：Outside the feed, tend a line of thought that's your own. Whatever you haven't looked at stays in the fog: no counts, no nudges.
- 副标题（中）：在推荐流外，维护一套你自己的思路。没看的留在雾里，不计数，也不催。
- 首屏画面：整屏是缓慢漂动的点阵雾，用有序抖动的灰点做成，浅色模式是纸上的墨点，深色模式是墨上的灰点，不显示任何数字。0–0.6 秒雾点淡入；0.6–1.4 秒只在画面左侧偏中的一处，雾点向四周退开，让出一个硬币大小、边缘是锯齿点的圆洞，别处的雾一点不动；洞里底色深一层，三颗点阵星星 `* . *` 隔几秒各闪一下。1.4–2 秒 ASCII 鹭从洞口往上探头，上升那一下散成字符，停住后归位，脖子以下还在洞里。名字用现代无衬线小写字体放在洞下方。指针在雾上移动时跟着开一个小洞，露出一条收藏的片段（一行转写加 03:42，标「机器转写」），指针离开后雾慢慢合拢，不留痕迹，也不记「已看过」。减少动态效果时只显示一帧静态画面。
- 名字解释：pertugio（读作 per-TOO-jo）是意大利语的「小洞」：《地狱篇》快结束时，但丁就是透过一个圆圆的小洞（per un pertugio tondo）望见天上的美好，下一行便是重见星星。
- README 开头（英）：

  ```markdown
  # pertugio

  Pertugio (per-TOO-jo, Italian for "a small opening") keeps the videos and posts you save on Douyin, Xiaohongshu, Bilibili, WeChat, X and elsewhere as plain files on your own computer. Speech and on-screen text become searchable and are marked as machine transcripts, so searching one sentence takes you to the second it was said.

  What you saved can stay in the fog. You look in wherever you like, and nothing counts what you skipped.
  ```

- README 开头（中）：

  ```markdown
  # pertugio

  pertugio（读作 per-TOO-jo，意大利语「小洞」）把你在抖音、小红书、B 站、公众号、X 等平台收下的视频和帖子，原样存成你电脑上的普通文件。口播和画面里的字转成能搜的文字，标明是机器转写；搜一句话，就跳到视频里说出它的那一秒。

  收下的东西可以一直留在雾里。想看哪里，就在哪里开一个小洞；没看的不计数，也不催。
  ```

- 各平台标题：
  - HN：Show HN: Pertugio – Local, searchable copies of the videos and posts you saved
  - Product Hunt：Saved videos and posts, local and searchable to the second
  - V2EX：收藏了几百条不知从哪看起，做了个 pertugio：各平台收下的东西存到本地，搜一句话跳到视频里那一秒（开源）
  - 小红书：收藏几百条不知从哪看起？我做了个小工具
  - 即刻：收了几百条视频一直没点开，于是做了 pertugio：一张雾里的地图，想看哪儿就在哪儿开个小洞
- 命令示例：

  ```console
  $ pertugio plugin add burella/bilibili      # 插件仓库的 GitHub topic 是 pertugio-plugin
  $ pertugio search "隔一天练反而恢复得更好"
    ~/.pertugio/bilibili/BV1…/  03:42  「…隔一天练，反而恢复得更好…」  [机器转写]
  $ pertugio open bilibili/BV1… --at 03:42    # 只打开这一条，从 03:42 播起
  $ pertugio note bilibili/BV1… "我试了两周，确实。"
  ```

- 外号：推断最可能流传的是「土鸡」（拼音拆读成「佩土鸡哦」）；认真介绍时会意译成「小洞」；照原音念的人写「佩图乔」。建议不躲「土鸡」，用贴纸主动认领；如果用户不想要这个梗，这一条就是硬伤，因为外号挡不住。正式中文页只写 pertugio，只翻副标题。
- 贴纸点子：主贴纸「是鹭，不是土鸡」：ASCII 鹭从圆洞 ( ) 里探出头，洞外三颗点阵星星。同系列：鹭只露出一只眼，配字「就看一眼」；鹭缩回洞里、只剩一圈点，配字「先不看了」。
- 宣传风险：
  1. 听一遍拼不出，8 个字母到上限，全站只用 per-TOO-jo 一种读法。
  2. 「土鸡」外号。
  3. 「洞」的联想：中文里有「漏洞」「钻洞」，英文 hole 有俚语义，所以英文首屏只写 opening / way in，small round hole 只出现在名字解释里；意大利语的性隐喻见 [§6](#6-词义核实与同名产品)。
  4. 来历要讲两层（但丁加《地狱篇》最后一行），只对意大利语用户和读过但丁的人起作用，首屏不能靠它；it.wikipedia 给这一行单独设了词条，说明在意大利确实广为人知。
  5. 地狱这个比喻：文案只写「透过小洞看见星星」，不写「逃出来」「走出来」，免得暗示有个终点。
  6. 「a riveder le stelle」在意大利有五星运动的政治联想，不当口号用。
  7. GitHub 上 star 相当于点赞，「看见星星」容易被写成求 star 的梗，避开。
  8. 中文平台上「pertugio 一下」偏长，宣传里的动词直接用中文「开个小洞」。

**Dokokara**

- 首屏标题（英）：Saved hundreds of things? Open them from any corner.
- 首屏标题（中）：收了几百条，不知道从哪看起？从哪一角打开都行。
- 副标题（英）：Outside the feed, keep a line of thought of your own: what you saved from Douyin, Bilibili, Xiaohongshu or X stays on your disk as plain files, and searching one sentence lands you on the second it was said.
- 副标题（中）：在推荐流外，维护一套你自己的思路：抖音、小红书、B站、X 上收下的东西存成你电脑里的普通文件，搜一句话就跳到视频里说出它的那一秒。
- 首屏画面：
  1. 整屏是缓慢流动的灰色点阵雾，疏密不均，没有任何数字或计数。
  2. 雾中间浮出一只点画的零食袋。袋子上沿是一排更密、更亮的小点：ja.wikipedia 写的是袋边有许多 0.2–0.3 毫米的细长小孔，不是锯齿，所以画成一排点，和点阵雾同一种笔触；只在袋角留两三个齿 `/\/\` 帮人认出是零食袋。
  3. 袋子上方用点阵字显示「dokokara?」，问号略淡。
  4. 鹭单脚站在袋子右边，约 1.2 秒后起步，一动身体就散成字符，落到袋边某一个点上重新聚成鹭，啄一下。啄的位置每次加载都随机；鼠标停在袋边任一点，那一点亮起，点一下鹭就飞过去。
  5. 被啄的地方撕开指甲大的一角，飘出三四个字符，接着是一行真实界面：一张视频卡片和一行转写「08:42 先挑一条看就好〔机器转写〕」。小口周围的雾变稀，别处照常流动。
  6. 问号后面打出「dokokara demo.」，下面一行小字：どこから？どこからでも。（从哪儿？从哪儿都行。）标题和副标题在这一帧淡入。
  7. 往下滚动时雾不会整体散开；减少动态效果时直接给最后一帧。
- 名字解释：Dokokara 是日语 どこから，意思是「从哪儿？」；日本零食袋边上常印着答案：这一边从哪儿都能撕开（包装原句待核实）。
- README 开头（英）：

  ```markdown
  # dokokara

  Keep what you saved from the feeds as plain files on your own computer, and open it from any corner. The rest can stay in the fog.

  *dokokara* (doh-koh-KAH-rah) is Japanese どこから, "from where?" Japanese snack bags print the answer along one edge: you can tear this side open from anywhere.
  ```

- README 开头（中）：

  ```markdown
  # dokokara

  把你在各平台收下的视频、帖子和长文存成自己电脑上的普通文件，从哪一角打开都行，其余的留在雾里。

  名字是日语 どこから（do-ko-ka-ra，「从哪儿？」）。日本零食袋边上印着答案：这一边从哪儿都能撕开。
  ```

- 各平台标题：
  - HN：Show HN: Dokokara – Your saved videos as local files, searchable to the second
  - Product Hunt：Saved posts and videos, kept local. Open from any corner.
  - V2EX：做了个开源本地工具 Dokokara：各平台收藏存到自己电脑，搜一句话跳到视频里那一秒
  - 小红书：收藏夹像一袋撕不开的零食？做了个从哪儿撕都行的开源小工具
  - 即刻：开源了 Dokokara：名字来自日本零食袋上那句「どこからでも切れます」，收藏也一样，从哪儿撕开都行（包装印字原句待核实，核实前别发这一条）
- 命令示例：

  ```console
  $ dokokara search "先挑一条看"
    bili/BV1…  08:42  先挑一条看就好            〔机器转写〕
  $ dokokara open bili/BV1…@08:42            # 跳到说出这句话的那一秒
  $ dokokara keep 做饭                         # 让「做饭」这一片一直清楚
  $ dokokara note bili/BV1… "我卡住的就是这个"    # 写下一句
  ```

- 外号：推断最可能是看图起的「零食袋」；音译「多口卡拉」可能缩成「多口」（碰巧是「多个口子」，但粤语里「多口」是多嘴）；懂日语的直接叫「doko」。
- 贴纸点子：两格。左格鹭两只脚踩住一只鼓鼓的点阵零食袋，喙咬着袋角往外扯，袋子纹丝不动，头上冒出 `# ! ?` 几个字符；右格同一只袋子，袋边一排小点里有一个亮了，鹭轻轻一啄，撕开一角，配字「从哪儿撕都行」。另做一张出错时用的：鹭扯不开袋子，配字「这次没撕开」。不画 マジックカット 的厨师标志。
- 宣传风险：
  1. 名字是问句，单独出现时像在复述问题，每处只露名字的地方，答句「どこからでも / 从哪儿都行」都要近在手边。
  2. 英文读者会把「dokokara demo」读成「Dokokara 的演示」，可以当梗用，但在解释 でも 之前别单独放。
  3. 解释有三层（どこから、零食袋印字、新干线熏鱿鱼故事），首屏只用前两层，故事放 README 的 About the name；中文用户里有多少人见过这行印字，待核实。
  4. マジックカット 是注册商标：讲故事注明出处，不当功能名，不借厨师标志；故事细节按维基原文写。
  5. 「撕」在中文网络有「开撕、撕逼」义；小红书标题可以用，宣传页正文改说「从哪儿打开都行」。
  6. 日文搜索基本用不上；「その痛み、どこから？」一类健康广告带一点医疗联想。
  7. 8 个字母四个音节，压在标准第 6 条的上限，中文外号多半靠图起。
  8. 评论区可能有人问「为什么起日语名」（推断）。
  9. 承诺边界：只说撕开一角、剩下的照样封着，不说拆完整袋，也不往「一撕就解决收藏焦虑」的健康产品说法上靠。

## 8. 上一轮的四个名字

上一轮的推荐和备选见 [调研 08 §0](08-english-name.md#0-推荐)。这一轮没有重查它们的可用性，用的是 08 的记录；三位终评评委把它们和本轮 20 个细查名放在一起排，四个都没进任何一位评委的前 8，各 0 票。

| 名字 | 08 票数 | 本轮票数 | 按第三版标准的结论 |
|---|---|---|---|
| Guddle | 22 / 24 | 0 | 半站得住，靠梗撑着：第 1 条不过 |
| Grepling | 19 / 24 | 0 | 站不住：第 1、4、5 条不过 |
| Fogdog | 15 / 24 | 0 | 勉强站得住，排不进前列：踩「直接叫雾」的坑 |
| Butterbump | 12 / 24 | 0 | 站不住：第 1、6、8 条不过 |

**Guddle**（苏格兰词，伸手到溪边石头底下徒手摸鱼）

- 概念与宣传效果评委：「摸鱼」梗在中文圈很强，鹭探石缝叼鱼也好画，但和雾、脑雾、「从哪开始」没有关系；中文直译「摸鱼」又会被当成上班划水工具；AlternativeTo 上还有同名项目。
- 独特与长期评委：第 1 条不过；裸名在一个有 6 个仓库的个人号手里；「摸鱼」先被读成上班划水，独特性和不被误解两条都是黄的。
- 中文用户与传播评委：在中文平台上传播力仍然最强，标题天然带流量；但「摸鱼」的通行意思是划水，产品会被当成摸鱼神器，也碰不到雾，降为备选。

**Grepling**（grep + -ling）

- 概念与宣传效果评委：只在开发者圈成立，普通中文用户念「格瑞普林」，和雾无关，第 1、4、5 条都不过。
- 独特与长期评委：命名空间全空，长期最干净；但梗只在开发者圈成立，和 Greptile 同一种造法，跟雾也没关系，商标没查。
- 中文用户与传播评委：长不出外号，和雾的概念没关系。

**Fogdog**（雾层里出现的一小块亮斑）

- 概念与宣传效果评委：四个里唯一碰到「口子」的，本义就是雾里透出来的一小片；但直接叫雾，吉祥物要换成狗，加拿大有两件 FOGDOG 商标，历史上有 Fogdog Sports，英文里 fogdog 还常被说成雾快散的征兆，容易滑向「清雾」。
- 独特与长期评委：在第三版的坑里；fogdog.com 由品牌保护公司托管，加上商标和 Fogdog Sports 的历史，长期看最可能被迫改名，和 Hoarder 同类风险。
- 中文用户与传播评委：外号「雾狗」好叫也无害，但鹭这条线会断，裸名被占，只能算黄。

**Butterbump**（英格兰方言里对大麻鳽的老叫法，叫声像雾笛）

- 概念与宣传效果评委：鹭线不断、叫声有点诗意，但 10 个字母超长，和「从哪开始」无关，「黄油」外号撞 ACG 圈成人游戏的说法。
- 独特与长期评委：命名空间全空，但超过第 6 条的上限，和雾、入口没有关系。
- 中文用户与传播评委：在中文平台上一被提到就容易跑偏，第 6 条和第 8 条都不合格，可以出局。

独特与长期评委的总结：真要留一个，Fogdog 的概念最近，Grepling 的占用最干净，两个都不如 Pertugio。

## 10. 获取插件组织的名字

## 11. 待核实清单

定名前要补的，排在前面的可能推翻推荐。上一轮的清单见 [调研 08 §10](08-english-name.md#10-待核实清单)。

1. **正式商标检索。** 在 USPTO、EUIPO、UIBM、J-PlatPat、CNIPA 按第 9 类（软件）和第 42 类（软件服务）查 TOEDIP、PERTUGIO、DOKOKARA、ANAZURI；Dotford 顺带看含 FORD 的冲突风险。本篇只有网页搜索的商标信号。
2. **国内平台同名。** 小程序、国内安卓应用商店、小红书、B 站、抖音、公众号里有没有叫 toedip / pertugio / dokokara / anazuri 的产品或账号。小红书和视频号的标题、封面写法这次也没抓到。
3. **社交账号名。** X、Bluesky、Mastodon、小红书、B 站、即刻、Discord 上推荐名和备选的用户名是否可用（本轮没查）。
4. **找真人试读。** 找几个中文用户和非开发者念一遍、听一遍：toedip 会不会拆成 to-e-dip、外号是不是「脚趾」；pertugio 会不会被叫「土鸡」、用户能不能接受这个梗；dokokara 和 anazuri 读成什么。本篇所有读音和外号判断都是推断。
5. **用户对日语、意大利语词的口味。** Pertugio、Dokokara、Anazuri 都是具体的日常词或实物词，不是第一轮那类美学词，但用户会不会一眼把它们归进「外语雅词」，要用户直接表态。
6. **Toedip 的细节。** toedip.com 的持有人和用途；.app、.dev 的注册情况（只作同名信号）；韩语、现代希腊语有没有同形词。
7. **Pertugio 的细节。** 意大利语里「洞」的性隐喻有多普遍（Boggione-Casalegno 色情词汇词典待查）；西语 RAE 有没有这个词；Il Pertugio SRLS 酒吧怀疑者没有复查；Product Hunt 403 没查成。
8. **Dokokara 的细节。** 包装原句「こちら側のどこからでも切れます」的实物出处；中文用户里有多少人见过这行印字；日本网友吐槽「どこからでも切れない」是否常见；Product Hunt 没查。
9. **Anazuri 的细节。** 「穴」在日语网络俗语里的性暗示有没有词典出处；韩语、现代希腊语同形词。
10. **初筛的去留数字。** 按评委记录判致命的是 53 个，流程记录 187 − 135 = 52，差 1 个，流程没留下逐个去留记录。
11. **App Store 分区。** Tenagos、Itoguchi、Stikla 的中国区（[§5](#5-可用性与撞名) 里写了「未知」）。
12. **其他细查名的缺口。** Stikla 的冰岛电视节目 Stiklur 细节、冰岛专利局商标；Mosaku 的约鲁巴姓氏含义、韩语 모색；Kokodot 的商标注册状态（Ensky Co., Ltd. 已在用并标 ©）；Catflap 的 Pet Mate「CAT FLAP」美国商标现状和 Straight Dope 原文；Itoguchi 作姓氏的情况；Knothole 在韩语、现代希腊语里的同形词；Pukapuka 的日本、中国商标。
13. **词义和出处的缺口。** 「冰间湖」译名的出处；smeuse、lanthorn、huffler 的读音；贺拉斯 ab ovo 的《诗艺》原文；Iliad 10.274-276 那只鹭 LSJ 认为其实是 shearwater；ψηφίς、ὀπαῖον、ἀταρπός 在 Wiktionary 没有词条，只在 Logeion 查到；Opaion「欧派」、Pellos「佩洛西」、Balbis「芭比」等中文外号是推断；Nesis 的俄语近音没查词典；冰岛谚语「小草丘能掀翻重车」待核实；カンテラ 来自荷兰语 kandelaar 待核实。
14. **参考软件的来历。** [§2](#2-雾能给名字什么) 表中标「未核实」「待核实」的各项（Atuin、Ollama、Obsidian、Kagi、Bun、Excalidraw、tldraw、Hoppscotch、Immich、Mihon 的来历，以及 Ollama、Ghostty 的中文叫法）。
