# 一轮测试

照 2026-11-12 打包的应用（提交 `41256ad`）实际报出来的取法写的：14 个插件、60 种取法，做了的 35 种，其中 20 种在这台机器上现在就用得上。每种取法一行：怎么触发、要什么、这边验到哪。应用里的「获取插件」页是同一张表的活版本，以它为准；各取法的来历和记录到的情况在[取法清单](routes.md)。

<a id="怎么开始"></a>
## 怎么开始

- 应用：`/Users/mac/WorkSpace/desktop_Project/usuyo-app/usuyo.app`。
- 带 react-grab 的开发窗口：先关掉应用（两者用同一个端口），在仓库里跑 `just app-dev`。
- 粘贴框接整段分享文字，会取出里面第一条链接。
- 从文件导入请用「选文件」；拖进窗口这一条改了，没在窗口里试过。

<a id="出了问题看哪里"></a>
## 出了问题看哪里

| 哪里 | 有什么 |
|---|---|
| 「获取插件」页每种取法那一行 | 现在能不能用、缺什么、上一次调用的结果 |
| 条目页 | 没存下来的是哪几样、原因 |
| `~/Library/Application Support/usuyo/logs/fetch-failures.jsonl` | 每次失败一行：时间、插件、取法、错误码、一句话、平台原样回答的开头 |
| 浏览器脚本面板上的「复制诊断」 | 页面请求的结构（路径、状态、字段名和类型、认出了几条），不含任何内容 |
| 「手机」页的「看一眼，不点」 | 驱动认出了屏幕上哪一步、对上了几处 |

失败日志里的那一行，或者「复制诊断」的文本，贴回来就能改。

<a id="这边真跑过的"></a>
## 这边真跑过的

都不用账号，经打包后的应用内核和装在这台机器上的插件跑的。

| 平台 | 取法 | 怎么触发 | 结果 |
|---|---|---|---|
| B站 | 公开接口 | 粘视频链接 | 完整存下，约 11 MB；随后自己合成能播的文件、取关键帧、认画面上的字 |
| B站 | 公开收藏夹 | 导入页 → B站 → 公开收藏夹，贴收藏夹或个人空间的链接 | 列出了一个公开收藏夹；设成私密的和稍后再看列不到 |
| X | 访客接口 | 粘帖子链接 | 存下；这台机器要经系统代理才连得上 X |
| 视频号 | 分享页接口 | 粘 `weixin.qq.com/sph/…` 链接 | 作者、描述、封面、发布时间；视频标为缺 |
| 快手 | 分享页 | 粘短链或 `short-video/…` 链接 | 完整存下，约 54 MB；图集的样子没碰到真样本 |
| 公众号 | 文章页 | 粘 `mp.weixin.qq.com/s/…` | 正文、52 张图、原样页面；带一长串参数的长链接两次落到校验页 |
| 知乎视频 | yt-dlp | 粘 `zvideo` 链接 | 720p 的视频、音频、封面 |
| 普通网页 | 通用网页 | 粘任何别的链接 | 存下 |
| 抖音 | 分享页 | 粘链接 | 取不到：平台 2026-08 起不在分享页给内容。条目只留链接并写明原因，不再换别的方式去请求 |
| YouTube | yt-dlp | 粘视频链接 | 只拿到标题、作者、简介；YouTube 回「先确认你不是机器人」。这台机器的 yt-dlp 是 2026.03.17，原因没分清是出口还是版本 |

<a id="做了没验过的"></a>
## 做了，没验过的

这些要账号、访客身份、你自己的文件或你自己装的工具，这边没法跑。出错在预期之内。

<a id="先在应用里领一次访客身份"></a>
### 先在应用里领一次访客身份

「获取插件」页上那个平台下面有「领访客身份」：应用开一个不登录的窗口打开那个网站，把这次访问的身份交给插件。

| 平台 | 取法 | 之后怎么触发 | 没验的是什么 |
|---|---|---|---|
| 小红书 | 公开笔记页 | 粘带 `xsec_token` 的笔记链接 | 整条路；领身份的窗口 |
| 微博 | 公开微博页的数据接口 | 粘微博链接 | 整条路；回答的样子照公开资料写 |
| 知乎 | 公开页 | 粘回答、文章、想法的链接 | 整条路；不带身份的请求知乎回校验页，带了够不够不知道 |

<a id="浏览器脚本"></a>
### 浏览器脚本

在脚本管理器（Violentmonkey、Tampermonkey）里装上脚本，在应用的导入页签发一个投递令牌，打开你自己的那一页往下翻，点面板上的「交给 usuyo」。脚本都在 `usuyo-fetch/<平台>/userscript/` 下。

| 平台 | 交什么 | 没验的是什么 |
|---|---|---|
| X | 书签、喜欢 | 没在真浏览器里跑过 |
| 小红书 | 收藏、赞过 | 同上 |
| B站 | 收藏夹、稍后再看 | 同上；稍后再看回答的样子没实测 |
| 抖音 | 喜欢、收藏、各收藏夹 | 同上；回答的样子全照公开资料 |
| 微博 | 收藏、赞过 | 同上；页面路径和回答的样子全照公开资料 |
| 视频号 | 只有探针 | 照页面代码看，普通浏览器里拿不到列表；跑一次探针是确认 |

<a id="账号登录进应用的"></a>
### 账号登录进应用的

| 平台 | 取法 | 怎么触发 | 没验的是什么 |
|---|---|---|---|
| B站 | 我的收藏夹和稍后再看 | 插件页登录 B站，导入页选来源 | 登录窗口、整条路 |
| B站 | yutto（高清、字幕） | 装 yutto 和 ffmpeg、登录 B站，粘视频链接 | 真的 yutto 没跑过 |

<a id="从文件导入"></a>
### 从文件导入

导入页 →「从文件导入」，选读它的那一种，选文件，看预览，确认。手上没有任何一家的真文件，样子都照公开文档和工具的源码写。

| 读什么 | 取法 | 没验的是什么 |
|---|---|---|
| X 设置里申请下载的归档 | X · 官方归档 | 用样例走到了预览；真归档里有没有书签不确定 |
| Telegram Desktop 导出的 JSON | Telegram · 导出 | 「已保存消息」那一段的写法 |
| Instagram 数据下载（JSON） | Instagram · 数据下载 | 合集文件的样子是猜的 |
| Google Takeout 里 YouTube 那一份 | YouTube · Takeout | 播放列表 CSV 的两列布局没有可靠出处 |
| DouyinDataReview「导出数据」的 JSON | 抖音 · DouyinDataReview 导出 | 整条路；点赞、收藏的时间它没写进文件 |
| 你自己跑 MediaCrawler 得到的帖子文件 | 小红书、抖音、快手、B站、微博、知乎 · MediaCrawler 的结果文件 | 整条路。默认关着，要先在插件页打开；它的文件里作者名是打了码的；小红书的链接不带 `xsec_token` |

<a id="你自己装和开着的工具"></a>
### 你自己装和开着的工具

工具没装、没开、令牌没填时，插件页那一行会写明缺什么，只挡这一种取法。

| 平台 | 取法 | 要什么 |
|---|---|---|
| 小红书 | XHS-Downloader | 它以 API 模式在本机运行；它启动时给的令牌填进插件设置；它配置里的 cookie 留空 |
| 快手 | KS-Downloader | 它以 API 模式运行，启动加 `--host 127.0.0.1`（默认对局域网开放）；它配置里放一份没登录的网页 cookie |
| YouTube、微博、Instagram、Reddit、X 的视频 | yt-dlp | 装了 yt-dlp 和 ffmpeg；在 YouTube、微博、Instagram 上这种取法层级更高、默认关着 |

<a id="手机"></a>
### 手机

「手机」页读得出这台机器的状态（macOS 15.6.1、有 iPhone 镜像、驱动没装、adb 37.0.1）。下面这些都没验过，第一次真装才知道：

- 「装上」：从官方 release 取驱动、对校验值、放进应用自己的目录。
- 登记驱动的后台服务：页面给两条命令，你到终端跑；它往登录钥匙串加一张驱动自己生成的签名证书、加一个登录项。
- 给「屏幕录制」「辅助功能」两项授权，读它们的状态。
- 剪贴板「试一下」、「看一眼，不点」、安卓的「找一下连着的手机」。

「看一眼」现在对不上任何流程：还没有哪个插件带流程文件。

<a id="等你定的"></a>
## 等你定的

1. 登记驱动后台服务：页面只给命令（现在这样），还是做成一个写明后果的按钮、由应用替你跑。
2. 「MediaCrawler 的结果文件」现在标成最高一层、默认关着；读文件本身不联网，要不要换个标法。
3. `usuyo-fetch/x` 的说明文档的写法；其余仓库的说明等你的意见再统一写。
