# 一轮测试

照现在各插件的清单（`usuyo-fetch/*/usuyo-plugin.yaml`）和预装的通用网页插件写的：13 个插件、48 种获取方式，已实现的 25 种；TikTok、贴吧、Reddit、QQ 四个仓库是占位，还没有清单。每种获取方式一行：怎么触发、要什么、这边验到哪。应用里的「获取插件」页是同一张表的活版本，以它为准；每种获取方式的做法和风险层级在各插件仓库的 README，跨平台的总览在[各平台的获取方式](routes.md)。

<a id="怎么开始"></a>
## 怎么开始

- 应用：`/Users/mac/WorkSpace/desktop_Project/usuyo-app/usuyo.app`。
- 带 react-grab 的开发窗口：先关掉应用（两者用同一个端口），在仓库里跑 `just app-dev`。
- 粘贴框接整段分享文字，会取出里面第一条链接；一次交多条链接用导入页的「粘贴链接」（每条都认，重复的合并，认不出的列在预览里，确认后按各平台的请求频率逐条添加）。
- 从文件导入请用「选文件」；拖进窗口这一条改了，没在窗口里试过。

<a id="出了问题看哪里"></a>
## 出了问题看哪里

| 哪里 | 有什么 |
|---|---|
| 「获取插件」页每种获取方式那一行 | 现在能不能用、缺什么、上一次调用的结果 |

| 浏览器脚本面板上的「复制诊断」 | 页面请求的结构（路径、状态、字段名和类型、认出了几条），不含任何内容 |

失败日志里的那一行，或者「复制诊断」的文本，贴回来就能改。

<a id="这边真跑过的"></a>
## 这边真跑过的

都不用账号，经打包后的应用内核和装在这台机器上的插件跑的；每一种的结果记在[各平台的获取方式 §4](routes.md#4-对真平台跑过的记录)。

| 平台 | 获取方式 | 怎么触发 |
|---|---|---|
| B站 | 公开接口 | 粘视频链接 |
| B站 | 公开收藏夹 | 导入页 → B站 → 公开收藏夹，贴收藏夹或个人空间的链接 |
| X | 访客接口 | 粘帖子链接；这台机器要经系统代理才连得上 X |
| 视频号 | 分享页接口 | 粘 `weixin.qq.com/sph/…` 链接；多条在导入页「粘贴链接」一次贴进去 |
| 快手 | 分享页 | 粘短链或 `short-video/…` 链接 |
| 公众号 | 文章页 | 粘 `mp.weixin.qq.com/s/…` |
| 抖音 | 分享页 | 粘链接；现在取不到，条目只留链接并写明原因，不再换别的方式去请求 |
| 普通网页 | 通用网页 | 粘任何别的链接；存下 |

<a id="做了没验过的"></a>
## 做了，没验过的

这些要账号、访客身份、你自己的文件或你自己装的工具，这边没法跑。出错在预期之内。

<a id="访客身份"></a>
### 访客身份

缺访客身份或平台不认时，应用自己开一个看不见、不登录的窗口打开那个网站，把这次访问的身份交给插件，再试一次；也可以在「获取插件」页上那个平台下面点「获取访客身份」。

| 平台 | 获取方式 | 怎么触发 | 没验的是什么 |
|---|---|---|---|
| 小红书 | 公开笔记页 | 粘带 `xsec_token` 的笔记链接 | 整条路；取身份的那个看不见的窗口。11-15 两次都被送去 `/login`，改了以后要看的几样在 [anonymous-content §11](anonymous-content.md#11-要真跑一次才知道的) |
| 微博 | 公开微博页的数据接口 | 粘微博链接 | 整条路；回答的样子照公开资料写 |
| 知乎 | 公开页 | 粘回答、文章、想法的链接 | 整条路；不带身份的请求知乎回校验页，带了够不够不知道 |

<a id="浏览器脚本"></a>
### 浏览器脚本

在脚本管理器（Violentmonkey、Tampermonkey）里装上脚本，在应用的导入页签发一个投递令牌，打开你自己的那一页往下翻，点面板上的「交给 usuyo」。脚本都在 `usuyo-fetch/<平台>/userscript/` 下。

| 平台 | 交什么 | 没验的是什么 |
|---|---|---|
| X | 书签、喜欢 | 没在真浏览器里跑过 |
| 小红书 | 收藏、赞过 | 同上 |
| B站 | 收藏夹、稍后再看 | 同上；稍后再看回答的样子没实测 |
| 抖音 | 喜欢、收藏、各收藏夹 | 同上；回答的样子全照公开资料 |
| 微博 | 收藏、赞过 | 同上；页面路径和回答的样子全照公开资料 |
| 视频号 | 只有探针 | 照页面代码看，普通浏览器里拿不到列表；跑一次探针是确认 |

<a id="账号登录进应用的"></a>
### 账号登录进应用的

| 平台 | 获取方式 | 怎么触发 | 没验的是什么 |
|---|---|---|---|
| 小红书 | 在 usuyo 中登录并读取 | 插件页上打开小红书的站点窗口并登录；窗口自己往下翻「收藏」再翻「赞过」（页面上写「点赞」），每读完一个列表就出现在导入页，都读过了自己结束，不用点「完成」 | 11-15 真跑读完收藏 382 条；改过的部分只对本机的假站点测过：扫码前不再算登录（要 `loggedIn` 为真或侧栏有你的个人页链接）、找不到的列表跳过并写原因、读完一个列表就交、窗口标题跟着变 |
| B站 | 我的收藏夹和稍后再看 | 插件页登录 B站，导入页选来源 | 登录窗口、整条路 |
| 视频号 | 腾讯元宝换视频 | 插件页登录腾讯元宝（登录窗口里登录后点按「完成登录」，或导入从浏览器导出的 cookies.txt），获取策略不是「仅不使用账号」，再取同一条链接 | 对真平台的整条路；从 cookies.txt 到下载视频只对本机的假站点测过。没登录时导出的文件也导得进（[wechat-channels.md §3.4](wechat-channels.md#34-插件做成的样子)），第一次取时才回需要登录。记录到公开解析服务被大量调用后元宝账号被封；用微信登录元宝会不会连带微信号没核实 |

<a id="从文件导入"></a>
### 从文件导入

导入页 →「从文件导入」，选读它的那一种，选文件，看预览，确认。都是平台官方的导出；手上没有任何一家的真文件，样子都照公开文档写。

| 读什么 | 获取方式 | 没验的是什么 |
|---|---|---|
| X 设置里申请下载的归档 | X · 官方归档 | 用样例走到了预览；真归档里有没有书签不确定 |
| Telegram Desktop 导出的 JSON | Telegram · 导出 | 「已保存消息」那一段的写法 |
| Instagram 数据下载（JSON） | Instagram · 数据下载 | 合集文件的样子是猜的 |
| Google Takeout 里 YouTube 那一份 | YouTube · Takeout | 播放列表 CSV 的两列布局没有可靠出处 |

<a id="手机连接"></a>
### 手机连接

「手机连接」页读得出这台机器的状态（macOS 15.6.1、有 iPhone 镜像、驱动没装、adb 37.0.1）。下面这些都没验过，第一次真装才知道：

- 「装上」：从官方 release 取驱动、对校验值、放进应用自己的目录。
- 登记驱动的后台服务：页面给两条命令，你到终端跑；它往登录钥匙串加一张驱动自己生成的签名证书、加一个登录项。
- 给「屏幕录制」「辅助功能」两项授权，读它们的状态。
- 剪贴板「试一下」、「看一眼，不点」、安卓的「找一下连着的手机」。

「看一眼」现在对不上任何流程：还没有哪个插件带流程文件。

<a id="插件目录和订阅源11-13"></a>
### 插件目录和订阅源（11-13）

「获取插件」页换成了插件目录：订阅源 `usuyo-fetch/index` 里的插件和装着的插件在一起，卡片或列表（右上角切换，记住选的），能搜、按平台和状态筛；点一个，右边整块换成它的详情，装着的获取插件下面是原来那几张卡片。

| 试什么 | 怎么试 | 现在会怎样 |
|---|---|---|
| 订阅源读得到 | 打开「获取插件」，拉到底看「订阅源」 | 写「几点读取 · 12 个插件」；这边没有在窗口里看过 |
| 卡片和列表、搜索、筛选 | 切换、输入平台名、选「已安装」「有更新」「未安装」 | 切换回来还是上次选的 |
| 开发时装的插件 | `just dev-plugins` 装过的插件的详情 | 写「开发版本」，没有安装、更新、删除按钮 |
| 从订阅源安装、更新、删除 | 详情里点「安装」，发了新版本以后「更新到 x」，再「删除」 | 现在所有插件都「尚未发布」：各插件还没有发布包；要等插件仓库推了 tag、发了 release、索引刷新以后 |
| 添加和移除订阅源 | 在「订阅源」里输入 `owner/repo` 添加，再移除 | 没有 `index.json` 的仓库会写明找不到 |
