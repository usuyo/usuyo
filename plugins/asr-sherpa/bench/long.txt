早上起来先烧一壶水，等水开的时候把豆子磨好。磨豆机的刻度我一般调在中间偏细的位置，太细了容易萃取过度，喝起来发苦。
今天想聊聊怎么在家里做一杯像样的手冲。很多人觉得手冲很麻烦，其实只要掌握几个要点，比如水温、研磨度和注水的节奏，就能做出稳定的味道。
滤纸放进滤杯以后，先用热水把它冲湿，这一步既能去掉纸味，也能给滤杯和分享壶预热。冲完的水记得倒掉。
我们公司上周开了一个很长的 meeting，主要讨论下个季度的 roadmap。产品经理希望先把搜索做好，工程这边更关心性能和稳定性。
后端这次准备把老的接口迁移到新的 API 上，文档已经放在 GitHub 上了。大家有问题可以直接在 issue 里留言，不用再单独发消息。
说到写代码，我最近在学 Rust，它的所有权和借用规则一开始很难理解，但是习惯以后，编译器会帮你挡掉很多内存方面的错误。
周末去了一趟城郊的山里，空气特别好。山脚下有一家小店卖手工豆腐，老板说他们家的豆子都是自己种的，每天凌晨就开始磨浆。
回来的路上堵车堵了很久，我就在车里听了一期播客，讲的是城市里的人为什么越来越难静下心来读一本书。
主持人说，推荐算法让我们一直在刷新，每一条都很短，看完马上就忘了。真正留下来的，反而是那些你自己停下来想过的东西。
我觉得这个观点挺有意思的。所以最近我开始把看到的好内容存下来，过一段时间再回头看，看看自己当时为什么觉得它重要。
做饭这件事也是一样，菜谱看了一百遍，不如自己动手做一次。上次学做红烧肉，糖色炒过头了，整锅都是焦味，但下一次就知道火候了。
有朋友问我，学英语有没有什么捷径。我的回答是没有，只能每天坚持听和说。比如每天早上听一段 podcast，跟着读，慢慢就熟了。
现在很多人用 ChatGPT 或者别的 AI 工具帮忙写邮件，确实省时间。不过我还是建议自己先写一个草稿，再让工具帮你改，这样表达的还是你自己的意思。
天气预报说明天会下雨，气温也会降下来。出门记得带伞，最好再多穿一件外套，早晚温差比较大，容易感冒。
小区门口新开了一家面包店，主打的是全麦和黑麦面包。我买了一个试试，口感比较扎实，配上黄油和果酱正好当早餐。
最近在整理家里的书架，发现很多书买回来一直没看。干脆按照想读的顺序排了一下，每个月挑两本，读完再买新的。
如果你也喜欢摄影，建议先别急着换设备。手机的相机已经很好了，多出去拍，多观察光线，构图慢慢就会有感觉。
我们组下周要做一次 code review 的分享，主题是怎么写出别人容易看懂的代码。命名要清楚，函数不要太长，注释说明为什么这样做。
旅行的时候我喜欢住在老城区，走路就能逛完一大片街道。早上去菜市场看看当地人吃什么，比去景点有意思多了。
跑步坚持了三个月，最大的变化是睡得更好了。刚开始跑一公里就喘，现在可以慢慢跑完五公里，配速虽然不快，但是很舒服。
关于存钱，我的方法很简单，发工资以后先把一部分转到另一个账户，剩下的才是这个月能花的。这样不容易冲动消费。
晚上睡前尽量不看手机，屏幕的光会让大脑一直很兴奋。可以换成看纸质书，或者听一些轻音乐，很快就能睡着。
有人说咖啡因会影响睡眠，所以我下午三点以后就不喝咖啡了，换成花草茶或者温水。效果还不错，晚上不会翻来覆去。
最后再说回手冲。闷蒸的时候水量大概是粉的两倍，等三十秒左右，让二氧化碳排出来，然后再分两到三次把剩下的水注完。
注水的时候尽量绕着中心画小圈，不要直接冲到滤纸上。整个过程控制在两分半到三分钟之间，味道会比较平衡。
